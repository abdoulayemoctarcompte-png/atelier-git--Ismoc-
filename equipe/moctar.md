## Quiz

1. **Juste après `git commit`, où se trouve mon commit ?**
   Dans mon Codespace uniquement (historique local).
2. **Juste après `git push`, où se trouve-t-il ?**
   Sur GitHub (dépôt distant `origin`), accessible à toute l'équipe.
3. **Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?**
   Le commit est définitivement perdu, car il n'a jamais été envoyé sur GitHub.
